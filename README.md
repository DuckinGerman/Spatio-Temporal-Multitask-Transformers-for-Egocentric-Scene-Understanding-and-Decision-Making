# Spatio-Temporal-Multitask-Transformers-for-Egocentric-Scene-Understanding-and-Decision-Making

This work proposes a unified temporal multi-task framework for first-person perspective
scene understanding and decision-making. The goal is to enable a wearable vision
system for pedestrain to perceive surrounding environments and support navigation-
related decisions in dynamic city scene. The framework jointly performs object detection,
semantic segmentation, action prediction, direction prediction, and ego decision-making
prediction. A Swin Transformer backbone and Feature Pyramid Network are employed to
extract multi-scale spatial features. A temporal feature aggregation module is introduced
to utilize historical frame information using multi-scale deformable attention for action
and direction prediction. The two-stage ego framework also achieves more stable training
behavior and better ego decision-making performance. In summary, this work provides a
complete perception to decision pipeline for first-person perspective scene and offers a
baseline for future wearable navigation and assistive vision area.
